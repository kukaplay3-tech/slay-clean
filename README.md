# SLAY Clean

Расширение убирает Winline со страниц [Slay Award](https://slay-award.ru/). Оно скрывает спонсорские логотипы, ссылки на бота и блок розыгрыша с входом через Winline. Фоновое видео и заставку с вшитым логотипом заменяют иллюстрация с кристаллами и надпись SLAY. Логотипы на архивных фото закрываются точечными масками. Текст очищается и при загрузке страницы, и при появлении новых элементов. Название события в ссылке на Яндекс Календарь очищается отдельно, дата и время сохраняются.

## Установка

Скачайте исходники через **Code → Download ZIP** и распакуйте архив. В диалоге установки укажите папку, в которой лежит `manifest.json`.

- **Microsoft Edge** — откройте `edge://extensions`, включите режим разработчика и нажмите **Загрузить распакованное расширение**.
- **Google Chrome** — те же шаги на странице `chrome://extensions`.
- **Firefox** — откройте `about:debugging#/runtime/this-firefox`, нажмите **Загрузить временное дополнение** и выберите `manifest.json`. После перезапуска Firefox понадобится загрузить дополнение снова.

Если сайт уже открыт, обновите вкладку.

## Область действия

Расширение работает локально на `slay-award.ru` и `www.slay-award.ru`, не отправляет данные и не запрашивает дополнительных разрешений. Для встроенных в медиа логотипов используются правила под известные материалы сайта. Внешние страницы, PDF и сторонние видеоплееры находятся за пределами этих правил.

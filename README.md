# SLAY Clean

Расширение с открытым кодом, которое убирает брендинг Winline с сайта премии Slay Award. [Открыть сайт премии](https://slay-award.ru/)

**[Скачать ZIP](https://github.com/kukaplay3-tech/slay-clean/releases/latest/download/slay-clean.zip)** · [Релиз и контрольная сумма](https://github.com/kukaplay3-tech/slay-clean/releases/latest) · [Проверка безопасности](SECURITY.md)

## Что меняется на сайте

- Скрываются логотипы Winline, ссылки на спонсорского бота и блок розыгрыша с входом через Winline.
- Фоновое видео с логотипом заменяется иллюстрацией с кристаллами. На первом кадре карусели логотипы отретушированы, на остальных известных фото закрыты точечными масками.
- Упоминания удаляются и из новых элементов, которые появляются после загрузки. Название события в ссылке на Яндекс Календарь очищается с сохранением даты и времени.

## Установка

1. Скачайте `slay-clean.zip` из [последнего релиза](https://github.com/kukaplay3-tech/slay-clean/releases/latest) и распакуйте его.
2. Загрузите расширение из папки `slay-clean`, в которой находится `manifest.json`.

   | Браузер | Где загрузить |
   | --- | --- |
   | Microsoft Edge | `edge://extensions` → **Режим разработчика** → **Загрузить распакованное расширение** |
   | Google Chrome | `chrome://extensions` → **Режим разработчика** → **Загрузить распакованное расширение** |
   | Firefox | `about:debugging#/runtime/this-firefox` → **Загрузить временное дополнение** → выбрать `manifest.json`. После перезапуска Firefox загрузите его снова. |

3. Откройте Slay Award или обновите вкладку.

Для обновления распакуйте новый ZIP поверх старой папки и нажмите **Обновить** на странице расширений, затем перезагрузите сайт.

## Как устроено расширение

Список сайтов ограничен `slay-award.ru` и `www.slay-award.ru`. JavaScript и CSS работают локально со страницей. В ZIP находятся те же файлы, что и в исходниках соответствующего релиза. [Код и способы проверки](SECURITY.md)

Маски рассчитаны на известные фото и видео сайта. PDF, внешние страницы и сторонние видеоплееры находятся за пределами этих правил.

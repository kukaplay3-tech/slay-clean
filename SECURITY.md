# Как проверить SLAY Clean

- [manifest.json](manifest.json) ограничивает запуск скрипта двумя адресами Slay Award. В нём отсутствуют дополнительные разрешения и фоновый процесс.
- [clean.js](clean.js) редактирует текст, ссылки и элементы страницы. В нём отсутствуют вызовы для отправки данных или загрузки скриптов из интернета.
- [clean.css](clean.css) задаёт правила отображения. В `hero.css` и `photo-1.css` находятся встроенные изображения WebP. ZIP содержит исходные файлы, документацию и PNG-иконки. Для установки достаточно распаковать архив.

## Проверка скачанного ZIP

Откройте PowerShell в папке, куда скачали архив, и выполните команду.

```powershell
Get-FileHash .\slay-clean.zip -Algorithm SHA256
```

Сравните поле `Hash` с контрольной суммой в описании релиза или в файле `slay-clean.zip.sha256`. Совпадение означает, что ZIP совпадает с опубликованным файлом. [Последний релиз](https://github.com/kukaplay3-tech/slay-clean/releases/latest)

Чтобы сверить содержимое с исходниками, откройте тег релиза в репозитории и сравните файлы с распакованным ZIP. Архив собирается напрямую из тега.

```sh
git archive --format=zip --prefix=slay-clean/ --output=slay-clean.zip v1.0.1
```

Для независимой проверки загрузите именно `slay-clean.zip` в антивирусный сервис. Условия VirusTotal предусматривают передачу отправленного файла участникам сообщества безопасности. [Проверить файл в VirusTotal](https://www.virustotal.com/gui/home/upload)

Если заметили подозрительное поведение, укажите версию расширения и шаги воспроизведения. [Сообщить о проблеме](https://github.com/kukaplay3-tech/slay-clean/issues)
